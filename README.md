# 慣性ラボ — ガリレオの思考実験

力学学習シリーズ第2弾。左右の斜面と滑らかな接続部を使って、慣性の法則を学ぶブラウザアプリです。

## 起動

`index.html` をブラウザで開いてください。インストールや外部ライブラリは不要で、オフラインでも動作します。

## 機能

- 右斜面の角度を0〜45°、0.1°刻みで調整
- 出発高さはボール中心の2.0 m、左斜面は30°に固定
- 斜面がある場合は最高点で折り返し、ユーザーが一時停止するまで往復
- 水平面では一定の速さで進み続ける
- 再生・一時停止・再開、出発点に戻す、再生速度の変更
- ボールに追従する高さ・速さの2行表示
- 2.0 mに固定した点線、2 m間隔の縦線と水平位置表示
- CSV保存：斜面は1往復分、水平は20秒分（0.01秒間隔＋終了時点）

## モデル

摩擦・空気抵抗・回転を省いた質点モデルです。直線斜面を接線方向が連続する円弧で接続し、エネルギー保存から運動を計算します。高さはボール中心の値です。表示上の斜面はボール半径に合わせて中心経路からずらして描画しています。

## ファイル

- `index.html`：画面と説明
- `app.js`：操作、描画、CSV出力
- `physics.js`：経路と運動計算
